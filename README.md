# Индекс ментального благополучия — сайт

Черновик сайта к докладу «Пока мы справляемся: Индекс ментального благополучия
работающих россиян, 2026». Исследование ФОМ и Просебя.

**Живая версия:** https://leratk22.github.io/mental-index/

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `dashboard.html` | Демо дашборда |
| `privacy.html` | Заглушка политики обработки ПДн |
| `docs/TZ.md` | **Техническое задание** — структура, решения, открытые вопросы |
| `docs/TOKENS.md` | Дизайн-токены: откуда взяты цвета, шрифты, размеры |

Сайт статический: ни сборки, ни зависимостей. Открывается как есть.

## Как посмотреть локально

```bash
python3 -m http.server 4173
```

Затем открыть http://localhost:4173

## ⚠️ Это черновик, а не готовый сайт

Ждут замены:

- **Тексты карточек состояний** — рыба, нужен текст из части 2 доклада
- **Цитата эксперта** — ожидает согласования
- **Кейс Билайна** — все формулировки в квадратных скобках.
  Флаг `caseBeeline` в `assets/js/content.js` сейчас `true`, чтобы блок был виден.
  **Перед публикацией:** либо согласованный с маркетингом Билайна контент, либо флаг в `false`
- **Формы и сбор лидов** — не реализованы, кнопки пока не отправляют данные
- **PDF доклада** — файла нет
- **Картинка превью для Telegram** (`assets/img/og-cover.png`) — отсутствует

## Правила, которые легко нарушить

**Кеширование.** У всех ссылок на CSS, JS и картинки стоит версия `?v=...`.
Меняете стиль, скрипт или изображение — **поднимите версию во всех трёх html-файлах**,
иначе у посетителей останется старая версия. Сам HTML должен отдаваться
с `Cache-Control: no-cache`.

**Цифры исследования** правятся только в `assets/js/content.js`, не в разметке.

**Неразрывные пробелы.** В HTML — `&nbsp;`. В `content.js` — символ U+00A0:
значения подставляются через `textContent`, и сущность отрисовалась бы буквально.

## Шрифты

Euclid Circular A, набор **WebM** — в нём есть кириллица. В наборе WebS её нет,
для русского сайта он не годится.

⚠️ Шрифт коммерческий (Swiss Typefaces). Файлы лежат в `assets/fonts/` и в этом
публичном репозитории доступны для скачивания. Нужно проверить, покрывает ли
лицензия Просебя веб-использование и публичное размещение файлов — лицензии
на приложение и на веб продаются отдельно. Если нет, шрифты убираются из репозитория,
а сайт остаётся на запасной гарнитуре.
