# Токены: откуда взяты значения

Результат переноса: [assets/css/tokens.css](../assets/css/tokens.css).

Два источника:

| Что | Откуда |
|---|---|
| Типографика, радиусы, отступы, тень | `design-tokens.tokens.json` — экспорт из Figma |
| **Цвета** | **Живая дизайн-система: `prosebya.vercel.app`, Storybook** |

---

## 1. Почему цвета пришлось брать из Storybook

В Figma-экспорте оказался только семантический слой — `color.bg.*`, `color.fg.*`, `color.border.*`. Каждый токен ссылается на коллекцию `primitives`, которой в файле нет:

```json
"bg": { "action": { "value": "{primitives.color.brand.orange}" } }
```

37 ссылок в никуда, ни одного hex. Значения вытащены из скомпилированной темы Storybook (режим **light**) и из компонента `UI/Button`.

**Если будете переэкспортировать из Figma** — включите коллекцию primitives, тогда источник станет один. Пока источник правды по цвету — Storybook.

## 2. ⚠️ Главное: акцент действия — жёлтый, не оранжевый

```
brand-orange = #FFB800   ← это ЖЁЛТЫЙ
brand-orange-hover = #F6A300
```

Токен исторически называется `brand-orange`, но значение — жёлтый, тот же, что заливает логотип Просебя. Имя в коде сохранено, чтобы совпадало с вашим Storybook; путаница живёт в системе, а не в этом проекте.

### Что из этого следует для вёрстки

Жёлтый на белом даёт контраст **1.73:1** — как текст он нечитаем в принципе. Поэтому жёлтый используется только как **заливка**, никогда как цвет текста на светлом фоне:

| Где | Решение | Контраст |
|---|---|---|
| Кнопка primary | жёлтая заливка, текст чернилами `#22263B` | 8.6:1 ✅ |
| Акцентное слово в заголовке, номера буллетов, «35%» в хиро | brand blue `#344079` | 9.7:1 ✅ |
| Цифра «35%» в тёмной секции | жёлтый на `#22263B` | 8.6:1 ✅ |
| Плашки «Демо-данные», «черновик» | бледно-жёлтая подложка, текст чернилами | ✅ |

Белый текст на жёлтой кнопке дал бы 1.73:1 — поэтому в системе он и не белый.

## 3. Кнопки — по компоненту `UI/Button`

| Вариант | Фон | Текст | Обводка |
|---|---|---|---|
| primary | `#FFB800`, hover `#F6A300` | `#22263B` | нет |
| secondary | прозрачный | `#344079` | `#344079` 20% |
| tertiary | прозрачный | `#344079` | нет |
| secondary inverted | прозрачный | белый | белый 10% |
| disabled | `#E7E9ED` | чернила 40% | `#E7E9ED` |

Скругление полное, начертание 600, размеры s/m/l = 12/14/16px.

**Одно отличие от системы:** горизонтальные отступы 28px вместо 16px. В приложении кнопка обычно растянута во всю ширину, на промо-странице она стоит сама по себе и при системном padding выглядит мелкой. Цвета, скругление и начертание — ровно как в системе.

## 4. Полная светлая палитра

**Примитивы**

```
core            #22263B    чернила (в тёмной теме — фон)
core-inverted   #FFFFFF
brand-orange    #FFB800    действие          hover #F6A300
brand-blue      #344079    акцент
gray-light      #F4F6FA    gray-core #EAEFF8    gray-muted #E7E9ED
positive        #759F45    negative  #F15D56
```

**Семантика (light)**

```
bg:      primary #FFF · secondary #EAEFF8 · tertiary #F4F6FA · accent #344079 · pressed #22263B0D
fg:      primary #22263B · secondary 80% · tertiary 60% · muted 40% · accent #344079
border:  primary 20% · secondary 10% · button-secondary #34407933 · button-tertiary #3440791A
```

`warning` в скомпилированной теме не нашёлся (класс нигде не используется) — взят брендовый жёлтый, он и по смыслу предупреждение.

### Про «тёмную тему» в Figma-экспорте
Ранее казалось, что экспорт снят в тёмном режиме: `color.system.white` ссылался на примитив `black`. Storybook это подтвердил — в системе `core` действительно чернила, а не белый. Никаких догадок не осталось, светлые значения взяты как есть из `light-*`.

## 5. Шрифт — файлы на месте

Веб-версии Euclid Circular A нашлись в лицензионном пакете `~/Documents/ProSebya/Euclid Circular A (1)/`. Скопированы в `assets/fonts/` четыре начертания: Regular, Medium, Semibold, SemiboldItalic. Всего 128 КБ.

**⚠️ Важно про набор символов.** В пакете три варианта — WebS / WebM / WebXL. Это не оптические размеры, а объём символов. Проверено загрузкой в браузер:

| Набор | Вес | Кириллица |
|---|---|---|
| WebS | ~20 КБ | **НЕТ** — только латиница |
| WebM | ~30 КБ | есть ← используем |
| WebXL | ~45 КБ | есть, плюс языки, которые сайту не нужны |

Для русскоязычного сайта **WebS брать нельзя** — вся кириллица уедет в фолбэк. Если кто-то будет обновлять шрифты, это первое, на что смотреть.

`local()` в `@font-face` намеренно не используется: у дизайнера шрифт установлен в системе и подменил бы файл, из-за чего поломка на его машине была бы не видна.

Остаётся проверить, покрывает ли лицензия веб-использование — она обычно продаётся отдельно от приложения. В папке лежит `eula.pdf`.

## 6. Что перенеслось из Figma без изменений

- **Типографика** — шкала `title / body / label / content / numbers / caption`, начертания 400 / 500 / 600 и italic («decorative»).
- **Радиусы** — 0 / 8 / 12 / 16 / 24 / 32 / 999, отдельно `checkbox: 6`.
- **Отступы** — шкала `gap`: 0, 2, 4, 8, 12, 16, 20, 24, 28, 32, 36, 48, 64, 128.
- **Тень** — `0 12px 24px -4px` при 5% непрозрачности.

Трекинг взят из стилей шрифта (в пикселях: −0.56 при кегле 28) и переведён в `em`, чтобы работать на любом размере.

## 7. Что добавлено для промо

Шкала приложения заканчивается на 28px — для десктопного лендинга мало. Добавлен display-слой, продолжающий ту же логику: чем крупнее кегль, тем плотнее трекинг.

| Токен | Размер | Где |
|---|---|---|
| `--size-display-xl` | 40 → 88px | H1 хиро |
| `--size-display-l` | 30 → 56px | H2 секций |
| `--size-display-m` | 24 → 40px | Цитата, заголовок дашборда |
| `--size-display-s` | 20 → 28px | Заголовки карточек |
| `--size-stat` | 48 → 104px | Акцентная цифра хиро |
| `--size-stat-s` | 36 → 64px | Цифры «Знаете ли вы?» |
| `--size-lead` | 17 → 22px | Подзаголовок хиро |
| `--size-promo-body` | 16 → 18px | Основной текст лендинга |

Всё через `clamp()` — без брейкпоинта под каждый заголовок. App-шкала не тронута, дашборд свёрстан на ней.

Также добавлено, чего в Figma не было: вертикальный ритм секций, ширины контейнера, кривые и длительности анимаций, z-индексы.

## 8. Цвета трёх состояний — единственное, что придумано с нуля

Токенов под «В напряжении / В хрупком равновесии / В ресурсе» в системе нет.

```
strain    #A83E28   подложка #F7ECE8
fragile   #C08A3E   подложка #F9F0E2
resource  #008E8C   подложка #E6F1F0   (было #3F8886 — см. § 10)
```

Три требования и как они выполнены:

**Не светофор.** Шкала идёт от тёплого к прохладному, а не красный → жёлтый → зелёный. Тема чувствительная: «В напряжении» не должно читаться как «сломан».

**Не путаются с кнопкой.** Охра приглушена намеренно — рядом с брендовым `#FFB800` яркий янтарь читался бы как призыв к действию.

**Различимы без цвета.** Светлота 12 / 30 / 20 — далеко друг от друга, поэтому оттенки не сливаются ни в ч/б, ни при дальтонизме. Это важно: теми же цветами будут закодированы доли на графиках дашборда.

**Почему заголовки карточек — чернилами, а не цветом состояния.** Чтобы цветной заголовок прошёл контраст на светлой подложке, все три оттенка пришлось бы затемнить до примерно одной светлоты — и они перестали бы различаться в ч/б. Разведя роли (цвет кодирует категорию на маркере и в графиках, текст остаётся чернилами), получаем и читаемый текст 14.9:1, и цвета, работающие без цвета. Контраст оттенков на белой карточке дашборда — 6.2 / 3.0 / 4.1 при пороге 3:1 для нетекстовой графики.

Ждут утверждения у Ксюши и Оли.

## 10. Графики дашборда (dataviz)

Токены `--viz-*` в `tokens.css`, § 10. Дашборд подключает `tokens.css` и берёт цвета графиков только оттуда — в SVG и разметке hex больше нет.

### Почему ушли от светофора

Дашборд до этого красил зоны и ответы в `#F15D56 / #FFD452 / #759F45`. Валидатор скилла dataviz (`validate_palette.js`, белая карточка, все пары):

```
#F15D56,#FFD452,#759F45
  FAIL  светлота: #FFD452 L 0.88 (вне 0.43–0.77)
  FAIL  дальтонизм: #759F45 ↔ #F15D56  ΔE 2.8 (дейтеранопия) — «риск» и «ресурс» сливаются
  WARN  контраст: #FFD452 1.42:1
```

Палитра трёх состояний проходит всё, кроме одного пункта — бирюзовый был ниже порога насыщенности (C 0.073 < 0.10, в графике читался как серый). Подняли насыщенность, светлоту и тон не трогали:

```
#A83E28,#C08A3E,#008E8C   --pairs all, поверхность #ffffff
  PASS  светлота — все три в 0.43–0.77
  PASS  насыщенность — все ≥ 0.10
  PASS  дальтонизм — худшая пара #008E8C ↔ #C08A3E  ΔE 11.9 (протан)
  PASS  обычное зрение — худшая пара ΔE 18.8
  PASS  контраст — все ≥ 3:1
```

Это меняет и лендинг: там `--color-state-resource` тоже используется (профили в `main.css`). Цвет стал заметно насыщеннее, но остался «средним прохладным».

### Акцент и контекст

| Токен | Значение | Зачем |
|---|---|---|
| `--viz-accent` | `#404E94` | Ряд, ради которого график (компания). Брендовый синий `#344079` на шаг светлее: исходный слишком тёмный для метки (L 0.39 при нижней границе 0.43). Как текст — 7.8:1 |
| `--viz-muted` | `#80889A` | Контекст: Россия, нейтральная группа. 3.6:1 на белом |
| `--viz-neg / --viz-mid / --viz-pos` | состояния | Риск / средняя зона / ресурс — ссылки на `--color-state-*` |
| `--viz-neu` | `#C3C9D4` | Серая середина диверджентной шкалы («затруднились») |
| `--viz-*-surface` | подложки состояний | Бледные зоны на шкале −100…+100 |
| `--viz-grid` / `--viz-axis` | `#E4E9F2` / `#A3ACBB` | Сетка на шаг от поверхности; ось заметнее сетки |
| `--viz-label` | `#5A6078` | Подписи на графике. 6.2:1 на белом (старые подписи осей `#98A0AE` давали 2.63:1 — ниже нормы для текста) |

### Правило формы: серый — всегда полый

Бирюзовый (`--viz-pos`) и серый (`--viz-muted`) при протанопии сливаются: ΔE 2.1. Эта пара встречается на странице «Ресурс производительности». Решено не цветом, а формой — на всём дашборде:

- **закрашенный** маркер — фокус, в цвете;
- **полый** серый — контекст (Россия, нейтральная группа).

Плюс прямые подписи рядов. Различие держится без цвета.

### Чего нет

Тёмной темы в проекте нет — ни на лендинге, ни на дашборде. Токены заведены только для светлой; тёмные значения потребуют отдельного прогона валидатора на тёмной поверхности, а не автоинверсии.
